# End-to-end results: spindoctor-qwerty-devin-cli 1.1.0

Run on 2026-10-11 (PT) in a clean-room copy (fresh clone in an empty folder, empty HOME, `env -i` with PATH=/usr/bin:/bin, no
access to engine development folders), following only this README: `python3 tools/set_python.py python3` (the Python switch, a
no-op on Linux) and `tests/devin_host_check.py`. The clone stayed unchanged (`git status` clean).

**Mode: host-simulated, with real Devin CLI component checks.** The real **Devin CLI** 3000.6.11 (38b3cbd2), the official binary
published on npm as `@cognition-ai/cli-linux-x64` (MIT), was installed on a Linux test machine and used without an account,
sign-in or API key. Managing plugins needs a signed-in account (`devin plugins install --local` answers "You must be logged in to
manage plugins"), and sessions use Devin's own model service, so the plugin wasn't installed in Devin and no session ran. Without
signing in, the real CLI loaded the plugin's components placed at project level (`.devin/skills`, `.devin/rules`, `.devin/agents`,
`.devin/mcp_config.json`): `devin skills list`, `devin rules list`, `devin doctor` and `devin mcp list/get`. The stand-in loader
then applies the documented Agent Plugins runtime conventions (expand `${PLUGIN_ROOT}`/`${PLUGIN_DATA}`, PLUGIN_ROOT and
PLUGIN_DATA in the environment, cwd = plugin root) and runs the full end-to-end suite through the MCP server.

**Format check:** Devin CLI plugins docs (docs.devin.ai/cli/extensibility/plugins/overview, read 2026-10-11): manifest precedence
`.devin-plugin/plugin.json` > `.claude-plugin/plugin.json` > root `plugin.json`; root-path expansion is documented for the Claude
layout (`${CLAUDE_PLUGIN_ROOT}`) and the Agent Plugins 1.0.0 layout (`${PLUGIN_ROOT}`, `${PLUGIN_DATA}`, cwd = plugin root),
but not for the native layout that 1.0 used. Unrecognized Agent Plugins `$schema` versions only get a warning; this repo declares
1.0.0, the version Devin names, and validates against the official 1.0.0 schemas. Rules use the Windsurf `trigger` front matter;
subagents use `agents/<name>.md`.

**Parity target:** the updated SpinDoctor 3.1.2. Publishing was approved by Russell on the basis of the updated 3.1.2 passing its
own suite 18/18, with the three 29-qubit test checks adapted to the 298-qubit limit.
